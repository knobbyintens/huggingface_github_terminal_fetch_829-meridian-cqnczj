# Meridian Corpus - Release Audit

Internal repository tracking release compliance for the Meridian corpus family.

## Where things are

- `docs/release_manifest.json` - artifacts currently in scope and their Hub
  locations
- `docs/licensing_policy.md` - the downstream reuse policy that governs license
  selection
- `docs/prior_triage.md` - informal notes from earlier triage rounds (not
  authoritative)

The open tracking issue lists the metadata still missing from the release
record.
